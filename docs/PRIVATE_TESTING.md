# Private testing build

This fork is configured for **full FlashGet Kids–style capability** under the **OpenParental** brand, for **your own devices and lab testing**.

- One-way audio, hide-from-launcher, live screen, location, rules, etc. are implemented or on the parity roadmap in `docs/PARITY_ROADMAP.md`.
- Do **not** ship this configuration to strangers or app stores without legal review and clear disclosure to device users.
- Do **not** copy FlashGet proprietary APKs, assets, or decompiled source — only reimplement behavior in this repository.
